# 内容与产品要求

## 页面范围

最终作品为一个全英文连续长页面，依次包含：

1. Xiaomi Financial Services Europe 品牌与服务总览。
2. 德国金融产品介绍。
3. 德国保险产品介绍。
4. 综合支持和法律提示。

## 金融内容

- 解释并对比 Balloon Finance 与 Operating Lease。
- 明确 36、48、60 个月期限。
- 展示首付、月供、期限、里程和期末安排等消费者关心的信息。
- 提供可交互的演示金融计算器。
- 所有数字必须标注为示意性、非约束性计算。
- 不暗示保证授信或保证通过审批。

## 保险内容

- 展示 Basis、Komfort、Premium 三档产品。
- Komfort 作为推荐档展示。
- 覆盖责任险、部分险、全险及电动车相关保护教育。
- 包含报价流程、eVB、理赔、道路救援和欧洲出行场景。
- 最终保障范围以 Allianz 正式条款为准。

## 合作关系与合规

- Santander 和 Allianz 的服务关系按已正式确定表述。
- 只使用合作方文字名称，不使用合作方 Logo。
- 不虚构正式费率、保费、免赔额、监管注册号或承保限额。
- 明确说明演示产品细节和法律主体角色仍需最终法律审核。
