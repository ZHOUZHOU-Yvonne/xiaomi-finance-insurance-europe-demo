# 本地运行说明

## 最简单的查看方式

进入 `03_Deliverable_最终作品/本地HTML版本`，直接双击以下任一文件：

- `01_europe_overview.html`
- `02_germany_financing.html`
- `03_germany_insurance.html`

三份页面已内嵌样式和车型图片，无需安装软件，也无需启动服务器。金融页面的计算器可离线操作；跳转 Allianz 等外部网站时仍需联网。

## 运行完整项目源码

## 环境要求

- Node.js 22.13.0 或更高版本。
- npm。

### 启动步骤

在终端进入 `03_Deliverable_最终作品/项目源码` 目录，然后执行：

```bash
npm install
npm run dev
```

终端显示本地地址后，在浏览器访问：

<http://localhost:3000/>

### 质量检查

```bash
npm run lint
npm test
```

`npm test` 会执行金融计算逻辑测试、生产构建、页面渲染测试和离线 HTML 完整性测试。

如页面内容发生更新，可重新生成三个本地 HTML：

```bash
npm run export:html
```

## 常见说明

- `node_modules` 未包含在交付包中，需要通过 `npm install` 安装。
- 离线 HTML 本身无需联网；Allianz 等外部链接需要联网。
- 本地运行不会修改线上版本。
